# Optional ElevenLabs AI video — 19 October 2026

The scene editor can generate product clips through ElevenLabs' Image & Video
API. Generation is optional; a completed clip is previewed before choosing
**Use this clip → Apply to scene**. Generating alone never changes the script
or a scene's selected media. **Keep current media** and **Cancel** preserve the
scene's existing choice. Regular script generation, reel previews and exports
never submit video-generation requests.

## Integration and safeguards

- Veo 3.1 Fast / Veo 3.1, 4/6/8 seconds, 9:16 or 16:9, 720p or 1080p.
  Product pictures or a video's opening frame can anchor the generation.
- Generated audio is disabled. Imported MP4 clips use the existing framing,
  duration, captions, narration, music and transition pipeline.
- Creation requires explicit opt-in and an idempotent client submission ID.
  Submission timeouts are saved as uncertain; paid creation is never
  automatically repeated or moved to another API key.
- Jobs persist locally across app restarts. Refresh uses the original key and
  retrieves an existing generation. Download/import failures can be retried
  without a new generation. Provider credentials and signed download URLs are
  excluded from local job records and browser responses.
- Imports require a playable MP4, bounded to 96 MB, from a public HTTPS result.
  Collection clips are assigned to their reference product.
- Generated media stays out of automatic scene cycling until explicitly chosen.
  Deleted imported clips are marked deleted in history and cannot silently
  reappear; pending jobs cannot recreate a deleted product.
